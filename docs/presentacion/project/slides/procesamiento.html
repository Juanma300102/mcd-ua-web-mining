La segunda mitad del proceso. Para puntuar el tono, PyTorch es el motor que hace las cuentas de las redes neuronales, Transformers de Hugging Face descarga los modelos ya entrenados y pysentimiento prepara el texto para robertuito; el modelo de lenguaje grande corre con Ollama en la placa de video. Para resumir, pandas agrupa por medio y por semana o mes y arma las ventanas alrededor de cada hito, y SciPy calcula los márgenes de error y decide si un cambio es claro. Al final, un script recalcula cada cifra del informe y la página dibuja los gráficos. Por debajo de todo: uv fija las versiones para que cualquiera reproduzca el entorno, Postgres en Docker guarda el historial de Dagster, pytest corre 296 pruebas sin salir a internet y cada cambio pasó por una propuesta en OpenSpec.
